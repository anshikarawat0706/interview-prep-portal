# Interview Prep Portal

A full-stack web-based Interview Preparation Portal designed to help users prepare for technical, HR, aptitude, and mock interviews in one place.

## 🚀 Features

- User Registration and Login
- Aptitude Practice
- Topic-based Aptitude Questions
  - Average
  - Mixture & Alligation
  - Percentage
  - Profit & Loss
  - General Aptitude
- Technical Interview Questions
- HR Interview Questions
- Mock Interview
- Bookmark Questions
- Progress Tracking
- User Profile Management
- Profile Picture Upload and Removal
- Change Password
- Show/Hide Password
- Light / Dark / System Theme
- Notification Preferences
- Help & Support

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## 📂 Project Modules

### Aptitude
Practice aptitude questions organized by different topics.

### Technical
Practice technical interview questions.

### HR
Prepare for common HR interview questions.

### Mock Interview
Practice through a mock interview experience.

### Bookmarks
Save important questions for later revision.

### Progress
Track interview preparation progress.

### Profile
Manage personal information, profile picture, notifications, theme preferences, and password.

## ⚙️ How to Run Locally

1. Install XAMPP.
2. Start **Apache** and **MySQL** from the XAMPP Control Panel.
3. Place the project folder inside:

   `C:\xampp\htdocs\`

4. Create a MySQL database named:

   `interview_prep_portal`

5. Configure the local database connection in `db.php`.

6. Open the project in your browser:

   `http://localhost/interview-prep-portal/`

## 🔐 Security

Database connection files and personal profile uploads are excluded from the public repository using `.gitignore`.
